# 📊 Customer Segmentation using K-Means Clustering

## 📌 Project Overview

This project is an **Unsupervised Machine Learning** application that performs **Customer Segmentation** using the **K-Means Clustering** algorithm. Users can upload any CSV dataset, select numerical features, determine the optimal number of clusters using the Elbow Method and Silhouette Analysis, visualize clusters interactively, and save clustering history using SQLite.

---

## 🚀 Features

- 📂 Upload any CSV dataset
- 🔍 Select numerical features for clustering
- 📈 Determine the optimal number of clusters using the Elbow Method
- 📊 Evaluate clustering quality using Silhouette Analysis
- 🎯 Perform Customer Segmentation using K-Means Clustering
- 📉 Interactive cluster visualization
- 📋 View previous clustering history
- 💾 Store clustering history in SQLite Database

## 🚀 How to Run the Project

### Clone the repository

```bash
git clone https://github.com/anaghaborkar62-netizen/Customer_Segmentation_Project.git
```

### Go to the project directory

```bash
cd Customer_Segmentation_Project
```

### Install the required dependencies

```bash
pip install -r requirements.txt
```

### Run the Streamlit application

```bash
streamlit run app.py
```
